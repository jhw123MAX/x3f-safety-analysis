# 倾转旋翼的安全账

《飞行汽车技术基础》课程作业-2。单文件网页，零外部依赖，双击 `index.html` 即可离线阅读。

- 对象：倾转旋翼 eVTOL（以公开的 **Joby S4** 为样本；承上一份《eVTOL 气动构型的技术账》的路线选择）
- 视角：系统安全工程——构型与转换段 → 审定基础 → FHA/STPA → FTA/CCA → 子系统 → 运行 → 论证
- 资料截止：2026-11

## 一句话结论

倾转旋翼的难点不在悬停也不在巡航，而在"转换"那几十秒；它的冗余做到了电机级，却救不了倾转作动器卡阻这个单点。

## 交互

- 顶部阅读进度条、吸附目录（随滚动高亮当前章）
- FHA 表点击表头排序
- 六个子系统标签页
- **转换段预算调节器**：拖动作动器卡阻率 λ、检测重构覆盖率 c、共因比例 β，实时算 P = λ(1−c) + βλ，并给出"要把单点压进预算，覆盖率需要多少"
- 风险矩阵点圆点，看场景、屏障与残余
- 右下角：回顶 / 打印（`P` 直接存 PDF，已做打印分页）

## 数据口径

一级硬约束（规章与审定路径）；二级厂商口径（六桨、每桨双电机、双逆变器、四组隔离电池、三套电传、丢一桨仍可控）；三级推定（转换走廊形态、严重度对应、各类概率）。

所有"推定/示例"数字都是量级演示，不是 S4 的实测值，也不构成对该型号适航符合性的判断。预算调节器默认 λ=10⁻⁵/h、c=99%、β=0.02 均为示例假设。
