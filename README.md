- 分析对象：小鹏汇天「陆地航母」分体式飞行汽车 —— 飞行体 **X3-F**（六轴六桨双涵道，最大起飞重量 ≤960 kg）

## 交互

- 顶部阅读进度条、吸附目录（随滚动高亮当前章）
- FHA 表点击表头排序
- 七个子系统标签页切换
- **预算调节器**：拖动 λ / β / 电池失效率三个滑杆，实时看 10⁻⁹ 预算如何被吃掉

- 右下角工具条：回顶 / 打印（`P` 可直接存 PDF，样式已做打印适配）

## 数据口径

页面按三级标注材料：一级硬约束（规章与证件）、二级厂商口径（构型与冗余配置）、三级推定（按公开构型与标准框架推导）。

文中标注「推定」「示例」的数字均为**量级演示**，不是 X3-F 的实测数据，也不构成对该型号适航符合性的判断。故障树与调节器的默认参数（λ=10⁻⁴/h、β=0.02、电池 10⁻⁶/h）都是示例假设。
